# 👶 i ate a baby 🌐

stupid lil website 🌈✨

## 🧭 Explore

- 🏠 `index.html` is the homepage.
- 📋 `thelist.html` builds the list of names and pictures.
- 🖼️ `thelist/` contains the pictures used by the list.
- 🎵 `nugget.mp3` supplies the homepage audio.
- 🎨 `COMICSANS.TTF` and `cursor.cur` add the site's visual style.

## 🚀 Preview locally

📁 Serve this directory with Python:

```sh
python -m http.server 8000
```

Then open [localhost:8000](http://localhost:8000). 🌐👀

## 🛠️ Editing

- 📝 Edit the HTML files to change page content.
- 🧩 Keep image and audio filenames in sync with their references.
- 🔤 Save text files as UTF-8 so the emoji render correctly.
- ♿ Decorative emoji use `aria-hidden="true"` alongside readable text.
